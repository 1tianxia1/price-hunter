0开始前必读（先看，能省两趟）

最重要的一条事实：CPS 联盟 API 全都不含历史价格

京东联盟、淘宝客、多多进宝这三家，回答的都是「现在卖多少钱、有没有券」。它们没有接口告诉你「过去 180 天卖过多少钱」。

所以 PriceHunter 的历史价格曲线必须单独接一个数据源，即本文第 5 节。不要在三家联盟后台里翻半天找历史价接口——找不到是正常的，不是你操作错了。

关于本教程的可信度

本文所有入口 URL 与流程均于 2026-09 通过公开资料与官网文档核实。但各平台后台改版频繁，按钮位置和菜单名称可能已变，域名和整体流程一般不会变。

凡标注 未确认 的内容，属于公开信息不足以定论的地方，请以平台官网当前页面为准——本文不做编造填充。

开始之前，先把这 4 样东西备齐

① 一个实名手机号
三家都要短信验证码。建议全程用同一个手机号，避免后面账号体系对不上。
② 身份证（个人主体）
三家都要求实名认证，个人主体用身份证 + 人脸核验即可，不需要营业执照。
③ 已备案域名（可选但强烈建议）
京东「网站管理」、淘宝客「网站管理」都要工信部 ICP 备案号。没有备案域名 → 直接走「导购媒体 / 社交媒体」通道，门槛低很多（第 6 节有对比）。
④ 一段「应用用途」话术
填错会被拒。推荐写法见第 6 节，不要写「自用比价工具」。
好消息：个人主体能申请全部 4 个 Key

本文 4 个数据源，个人身份均可申请，不强制营业执照。区别只在「能拿到的接口权限多少」和「审核快慢」。真正卡个人主体的是部分商用/订单类接口，PriceHunter 用到的商品查询 + 转链类接口个人主体够用。

2京东联盟 —— AppKey / AppSecret

JD
京东联盟
入口 https://union.jd.com　·　个人可申请　·　推荐第一个申请

2.1 先选对通道（这一步决定你等 10 分钟还是 3 天）

京东联盟后台有 3 个并列的媒体通道，都能拿到 AppKey/Secret，但门槛差别很大：

通道位置需要什么建议
导购媒体管理我的推广 → 推广管理 → 导购媒体管理名称 + 类型（微信/QQ 等）+ 账号，不要备案域名首选
社交媒体管理推广管理 → 社交媒体管理名称 + 主页地址 + 登录账号，不要备案域名备选
网站管理推广管理 → 网站管理必须已备案域名 + ICP 备案号；若备案主体非本人还需营业执照 + 授权书有域名再走
APP 管理推广管理 → APP 管理需上架应用市场的 APP（包名 + 下载地址），人工审核最慢不推荐
没有备案域名？走「导购媒体管理」，一样拿全 AppKey/Secret

PriceHunter 只需要调 jd.union.open.goods.query（关键词商品查询）这类只读接口，导购媒体通道的权限足够。不要为了申请 Key 专门去买域名备案，那是几周的周期。

2.3 文字步骤清单

  1. 注册 / 登录京东联盟
    打开 https://union.jd.com，用京东商城账号直接登录即可（没有就注册）。首次登录会提示完善个人信息——这段要如实填，涉及后续佣金结算，乱填会影响提现。
  2. 完成实名认证
    顶部导航「结算中心」按提示做实名认证 + 绑定银行卡。即使你现在不打算收佣金也建议先做完，部分接口权限与认证状态挂钩。
  3. 进入「我的推广 → 推广管理 → 导购媒体管理」
    无备案域名就走这条通道。
  4. 点右上角「创建导购媒体」，填表提交
    名称、导购类型（聊天工具）、媒体类型（微信）、账号、用途说明。用途说明别写「自用」，写法见第 6 节。
  5. 等待审核
    导购媒体通道通常较快；若走网站/APP 通道为人工审核，1–3 个工作日不等，具体时长官方未公示，本文不做保证。
  6. 点「查看」复制 app_key / app_secret
    立刻粘贴到本地一个临时文本文件里，别只留在浏览器。
  7. （可选但推荐）申请具体接口权限
    进入「我的工具 → 接口管理」，确认 jd.union.open.goods.query（关键词商品查询）已开通，未开通就点申请。PriceHunter 主要依赖此类只读查询接口。
  8. 创建推广位拿 PID
    「推广位管理 → 创建推广位」，名称随意。生成转链时要用。

2.4 填进 .env

本教程使用约定命名 JD_APP_KEY / JD_APP_SECRET。若工程师实现时用了别的名字（如 JD_UNION_APP_KEY），请以项目根目录 .env.example 里的实际变量名为准——改的是左边的名字，值照抄。

3.2 文字步骤清单

  1. 用支付宝实名认证的淘宝账号登录
    淘宝开放平台要求账号已完成支付宝实名认证。没有就去支付宝做实名。
  2. 进入淘宝联盟后台 pub.alimama.com
    「推广管理 → 媒体管理 → APP 管理」（或「网站管理」/「导购管理」），点「创建」。
  3. 跳转到 open.taobao.com，先成为开发者
    右上角「控制台」→ 提交开发者信息，完成开发者入驻（个人主体可）。
  4. 申请「广告推广」类应用标签
    官方流程：先拿应用标签权限，才能创建应用。淘宝客体系归属「广告推广」类。
  5. 等 5–7 个工作日
    官方明示：一般应用标签均需 5–7 个工作日审核周期。这是四家里最慢的一环，建议尽早提交。
  6. 创建应用 → 拿 AppKey / AppSecret
    应用管理 → 概览 → APP 证书。AppSecret 需点「查看」才显示。
  7. 申请「淘宝客基础 API」权限
    同页「API 权限」标签页里申请。未开通则调用会报权限不足。
  8. 了解流量限制
    未上线应用 5000 次/天；上线后默认 100 万次/天。个人自用完全够。另注：官方说明未上线应用 3 个月未上线会被系统删除——别申请完就放着不管。

4.2 文字步骤清单

  1. 注册拼多多开放平台账号
    打开 https://open.pinduoduo.com → 右上角「立即加入」→ 手机号注册。此账号与你的拼多多购物账号、多多进宝账号是三套独立体系，建议用同一手机号并记下密码。
  2. 选角色：「我是第三方开发者」
    身份类型选个人开发者，如实填身份信息与联系人信息，提交审核。
  3. 等资质审核（1–3 个工作日）
    多份第三方教程称「几小时内通过」，但官方未公示时长，按 1–3 个工作日预期。
  4. 控制台 → 我的应用 → 创建应用
    应用类型必须选「多多客联盟」。选错（如「商家后台系统」）则拿不到推广类接口。

    多多客联盟应用不需要发布到服务市场，审核通过即可用。
  7. 【关键】登录 jinbao.pinduoduo.com 绑定
    顶部菜单「API 权限」→ 填入 client_id → 保存。
  8. 做推广者备案 + 创建推广位（可选）
    「推广者备案」里，没有自有网站就选「他方平台 / 社交平台」+「个人账号」。再到「推广位管理」创建推广位拿 PID。

5历史价格 API —— 最容易踩空的一块

再强调一次：这一节和第 2/3/4 节完全无关

京东联盟、淘宝客、多多进宝都不提供历史价格。你要的第 4 个 Key 来自一个独立于三大联盟的第三方数据源，需要单独申请、单独付费（或有免费档）。

6常见坑与驳回原因

这节是「别人踩过的坑合集」。申请前花 3 分钟看完，能省下几轮驳回。

❌ 坑 1：应用用途填「自用比价工具」
这是最高频驳回原因。平台要的是「能带来流量的推广媒体」，「自用」等于告诉审核员「你不会给我带来任何推广价值」，直接拒。
❌ 坑 2：网站未备案 / 备案主体不符
京东「网站管理」、淘宝客「网站管理」都要 ICP 备案号。备案主体不是本人/本公司时，京东还要求上传营业执照 + 授权书。没备案就别选网站通道。
❌ 坑 3：回调地址不合规
填 localhost 有的平台接受、有的拒；填一个不存在的域名必拒。安全做法：填你能控制的 HTTPS 域名，没有就用 http://localhost:5173/callback 并接受可能需人工沟通。
❌ 坑 4：拼多多漏了「回多多进宝绑定」
client_id 拿到了，但没去 jinbao.pinduoduo.com 的「API 权限」绑定 → 调用报权限错误。以为是 Key 错了，其实少一步。
⚠ 坑 5：淘宝「应用标签」没申请就找「创建应用」
官方流程是先拿标签权限，再创建应用。而且标签审核 5–7 个工作日。找不到创建入口时，先去看标签审核状态。
⚠ 坑 6：淘宝应用 3 个月不上线会被删
官方明示：未上线应用限流 5000 次/天，3 个月内未上线会被系统删除。申请完记得回来用。
⚠ 坑 7：拿错值 —— Secret 当成 Key
Key 是公开标识，Secret 是签名密钥。两者填反会报签名错误。京东的 key 是 32 位十六进制，别把 PID 当 Key。
⚠ 坑 8：个人主体拿不到某些权限
订单查询、结算类、部分高佣接口常需企业主体。PriceHunter 用到的商品查询 + 券查询，个人主体够用。超出范围就别硬申，容易整号被风控。
❌ 坑 9：把 Secret 提交到 Git
Secret 泄露 = 你的 CPS 佣金被人盗用 + 应用被封。.env 必须在 .gitignore 里，提交前确认一次。
❌ 坑 10：找「代申请 / 代过审」
多为灰色渠道，用假资质批量注册，被查会连坐封号，且你的实名信息在对方手里。不要碰。

6.1 「应用用途」怎么写才容易过

✅ 推荐写法
「为自有导购工具（网页/小程序）提供京东 / 淘宝 / 拼多多商品的实时价格与优惠券查询能力，用于向终端用户展示价格对比与可用券信息，帮助用户做出购买决策。」
✅ 三个加分要素
① 有明确的载体（网页 / 公众号 / 小程序 / 社群）；② 有明确的受众（终端消费者）；③ 强调「查询与展示」，不提批量采集、不提数据转售。
这些词不要出现在用途说明里

自用 / 学习 / 测试 / 数据采集 / 爬取 / 批量 / 转售 / 内部使用 / 竞品分析 / 监控。
每一个都指向「你不会为平台带来推广价值」或「你在做数据搬运」，都是驳回高发词。

7合规提醒（红线）

以下 5 条是硬约束，不是建议
  1. 不得爬取。 所有数据只能来自官方 CPS 联盟 API 或已授权的第三方 API。包括「用浏览器自动化打开商品页」也属灰色地带，本项目明确排除。
  2. 不得逆向 / 绕过鉴权。 破解第三方接口的 token、签名算法，属于绕过技术保护措施，有明确法律风险。
  3. 不得超范围使用数据。 申请时勾选了哪些接口，就只用哪些。用商品查询接口去批量刷全站数据属于超范围，会被收回权限。
  4. 不得长期缓存商品数据。 多数联盟规范要求展示实时价格，禁止把商品库缓存下来当自己的数据库用。短期请求级缓存可以，长期落库不行（自建历史价只存价格数值与时间戳，且仅自用，不在此限）。
  5. CPS 推广需遵守各平台规范。 包括但不限于：不得虚假宣传、不得诱导点击、不得在未经许可的渠道投放、不得违规使用平台商标与logo。
密钥安全三条
  • Secret 只存在于服务端 .env，不进前端 bundle、不进 Git、不进日志。
  • 确认项目 .gitignore 含 .env。提交前跑一次 git status 检查。
  • 若怀疑泄露，立即到平台后台重置 Secret，不要等。
关于「个人自用」的合规边界

如果你只给自己和家人用、不对外提供服务，各平台的规范约束相对宽松。但密钥的获取条件不会因此降低——审核标准一样。一旦你把工具分享出去（哪怕只是发给朋友），就进入「推广行为」范畴，需遵守 CPS 规范。

9申请优先级建议

四家同时开，你会被四个不同的审核节奏拖住。按下面的顺序来，最快当天就能看到真实数据。

  • 1
    多多进宝（先做，性价比最高）
    个人开发者可申请、应用审核快（多份资料称「秒过」）、不需要备案域名。唯一麻烦是要跨两个站点绑定，但照图 9 走一遍就好。
    难度低 当天可见效
  • 2
    京东联盟 · 导购媒体通道（第二个）
    走「导购媒体管理」不要备案域名，门槛和多多进宝接近。京东商品的标准化程度高、价格接口稳定，是比价演示效果最好的一家。
    难度低 1–3 天
  • 3
    阿里妈妈淘宝客（今天就提交，然后放着等）
    应用标签审核要 5–7 个工作日，是全程最长的一环。所以它应该第一时间提交，然后在等待期间去做 1、2、4。顺序上「最先提交，最后拿到」。
    难度高 5–7 个工作日
  • 4
    历史价格 API（最后做，且允许做不出来）
    这块不确定性最高（服务商政策、主体要求、付费门槛都未确认），但不影响核心功能。拿不到就先留空，页面照常出比价和优惠券，历史价模块走空态或自建库兜底。
    难度高 可延后
一句话执行顺序

今天：提交淘宝客（因为最慢）→ 注册拼多多开放平台 → 注册京东联盟。
明后两天：跟着第 4、2 节的图走完多多进宝与京东，填进 .env，验证核心流程通了。
下周：淘宝客标签审核下来后补填，再攻历史价格 API。

只要 1、2 两家完成，PriceHunter 就已经是「真数据」了

不必等四个 Key 全齐才启动。架构上每个 Adapter 独立降级：配了哪家就走哪家真实数据，没配的就 Mock 并在页面上标注。先把两家跑通，比等四家齐了再一次性调试要稳得多。
