# 淘宝客权限包申请清单（对照联盟后台截图整理）

> 2026-09-08 | 对应后台入口：淘宝联盟开放平台 → 应用 → 权限管理
> 结论：16 个权限包申请 5 个，1 个下线勿用，其余等 CPS 返利期再申请。

## ✅ 必申请（5 个，按优先级排序）

### 1. 物料搜索【推广者】16516 ⭐最优先
- **用途**：跨平台比价的核心——按关键词搜同款商品（代码调用 `taobao.tbk.dg.material.optional`，之前报 `scope ids` 错误就是缺它）
- **申请理由（直接复制）**：
  > 本人运营比价导购网站"价格猎人"，面向普通消费者提供跨平台商品价格对比与优惠信息服务。需通过物料搜索接口，根据用户输入的商品关键词实时检索淘宝客商品，获取价格、店铺等信息用于同款比价展示。查询均由用户操作实时触发，无批量采集行为，不缓存存储商品库，严格遵守《淘宝客推广规范》。

### 2. 物料信息查询【公用】16189
- **用途**：商品基础信息（标题/价格/店铺），比价展示地基
- **申请理由**：
  > 比价导购网站"价格猎人"需通过该接口获取推广商品的标题、价格、店铺等基础信息，用于页面商品详情与价格对比展示，帮助用户获取准确优惠信息。数据仅用于实时页面展示，不做存储与二次分发，遵守淘宝客推广规范。

### 3. 商品物料获取【推广者】27939
- **用途**：按商品 ID 拿最新价格与优惠，保证比价结果实时
- **申请理由**：
  > 比价网站在完成同款匹配后，需按商品 ID 获取对应商品的最新价格与优惠信息，确保向用户展示的价格实时准确。仅针对用户查询命中的商品实时调用，无批量抓取，遵守淘宝客推广规范。

### 4. 物料精选【推广者】16518
- **用途**：含券商品列表，让"券后价"展示更全
- **申请理由**：
  > 比价导购网站需获取含优惠券的商品信息，在比价结果中向用户完整展示可用券及券后价，提升优惠信息透明度。由用户查询实时触发，不批量拉取，遵守淘宝客推广规范。

### 5. 淘口令生成【公用】11655
- **用途**：比价结果"去购买"生成淘口令跳转手淘，标准导购转化路径
- **申请理由**：
  > 比价结果页需引导用户跳转至淘宝完成购买，网站场景无法直接唤起手机淘宝，需通过淘口令生成接口为用户生成商品淘口令，属于正常导购转化路径，遵守淘宝客推广规范。

## 申请理由写作要点（审核逻辑）

1. **开头亮产品形态**：「本人运营比价导购网站"价格猎人"」——比"个人学习"通过率高一个量级
2. **说清接口用途**：搜什么、展示什么、给谁用，与接口能力一一对应
3. **主动承诺合规三件事**：用户触发实时查询 / 不批量采集 / 不存储商品库
4. **提《淘宝客推广规范》**
5. **禁用词**（出现即高危）：自用 / 学习 / 测试 / 采集 / 爬取 / 批量 / 转售 / 内部使用 / 竞品分析 / 监控

被驳回 → 改理由重新提交即可，常见驳回原因见 `api-key-guide.html` 常见坑一节。
